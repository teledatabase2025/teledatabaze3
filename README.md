# TKM – Telekomunikační modul 2026

Aktivní hlavní telefonní výpisy jsou omezeny na čtyři osoby: Tamara Vrbová, Sebastian Rýdl, Elvíra von den Linden a Damián Korda.

Veškerá data SMS, hovorů a vedlejších kontaktů jsou v `tkm-data.js`. Vedlejší kontakty mají připravená pole `DOPLNIT`, která lze později nahradit vlastními informacemi.

Kliknutí na SMS otevírá celé vlákno komunikace dané dvojice čísel. Kliknutí na vedlejší číslo otevře pouze informace o čísle; odtud se hráč vrací na výpis hlavního čísla, ze kterého přišel.
